# Nobel Atlas

Исследовательский сайт на Streamlit: Нобелевские лауреаты, география знаний и анализ награждений. Готовая база включена; для первого запуска интернет нужен только для установки Python-зависимостей. Приложение само не запускает парсинг.

**Исправления запуска от 29 октября 2026:** если Cloud зависает на установке или Colab показывает ошибку загрузки JavaScript, начните с [START_HERE_FIX.md](START_HERE_FIX.md). Пакет исправлений накладывается поверх существующего репозитория и не заменяет базу. Для Colab добавлен [готовый ноутбук](notebooks/Nobel_Atlas_Colab.ipynb).

## Быстрый запуск

Python **3.12**. Откройте терминал в папке, где лежит `app.py`:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

Выполните только одну команду активации, соответствующую вашей ОС. Обновлять базу перед первым запуском не нужно.

## Перенос в существующий GitHub → Streamlit

1. Сохраните текущую версию репозитория коммитом или отдельной веткой.
2. Распакуйте архив. Скопируйте **содержимое** папки `nobel_atlas` в корень своего репозитория. Замените `app.py`, `updater.py`, `requirements.txt`, `nobel_database.sqlite`. Добавьте папки `nobel`, `static`, `tests`, `docs`, `.streamlit`, `.github` и остальные файлы пакета.
3. Удалите/отключите прежний workflow обновления, если он лежит под другим именем: два обновлятора не должны одновременно писать базу. Новый файл — `.github/workflows/update_data.yml`.
4. Закоммитьте изменения. В Streamlit Community Cloud укажите прежний репозиторий, нужную ветку, **main file path `app.py`**, Python **3.12**. При необходимости выполните Reboot app после установки зависимостей.
5. Проверьте вкладки «Обзор», «Лауреаты», «Лаборатория», «О данных» и журнал запуска. Файл `.streamlit/config.toml` обязателен: он включает локальную подложку карт.
6. В GitHub → Actions выберите **Update Nobel data → Run workflow** для первой проверки. В Settings → Actions → General разрешите workflow запись в репозиторий. Если основная ветка защищена от прямой записи, настройте разрешённый процесс через pull request или отдельную ветку данных; не отключайте защиту без необходимости.

Приложение читает SQLite из репозитория. Новая база приходит на Streamlit вместе с изменением репозитория. Кэш данных учитывает время изменения и размер файла. Карты не требуют ключей Mapbox или платных сервисов.

## Что есть на сайте

| Где | Возможности |
|---|---|
| Обзор, верх | Карта рождения / работы / смерти, временная динамика, категории, распределение возраста, страны рождения, гендерный состав |
| Обзор, раскрываемый блок | Карта связей «рождение → работа», выделение человека, лимит линий, прозрачность, Sankey потоков стран |
| Обзор, дополнительные графики | Матрица категорий по десятилетиям, рейтинг учреждений, динамика суммы премии |
| Лауреаты | Поиск, оформленная карточка, формулировки заслуг, все премии человека, даты, места, аффилиации, проживание, доли, статусы, ссылки, полный JSON |
| Лаборатория | Сводные таблицы, собственная тепловая карта, выбор показателя, просмотр столбцов и выгрузка CSV / JSON |
| О данных | Заполненность полей, определения метрик, ограничения, полный реестр премий и неприсуждённые премии |

Всего **13 видов визуализации** при стандартной полной выборке. В боковой панели: годы, категория, человек/организация, пол, страны и города рождения/работы, континент, учреждение, возраст, страна смерти, статус премии, повторные награждения и наличие координат. Пустой список фильтра означает «все».

При открытии строятся шесть основных визуализаций. Остальные вкладки и раскрываемые блоки вычисляются при открытии. В «Лаборатории» полный JSON сначала готовится кнопкой, затем скачивается. Это уменьшает нагрузку на запуск и не сокращает доступные данные.

## Обновление

```bash
python updater.py
```

Это полноценное обновление обоих endpoint API 2.1. Включённый снимок на **27 октября 2026**: **1 028 лауреатов**, **1 036 награждений**, **688 записей «год × категория»**, **856 аффилиаций**, **233 записи проживания**. Число объектов сверено с `meta.count`; наборы награждений сверены между endpoint.

Загружаются все страницы, а не только новые люди: API может исправить старые биографии, даты смерти, суммы и учреждения. На этом размере данных полный проход требует всего трёх запросов. Между запросами пауза не менее 1,1 секунды; запросы последовательные, с таймаутом, повторением временных ошибок и учётом `Retry-After`. При слишком долгой рекомендованной паузе процесс завершится без изменения базы.

Перед заменой проверяются страницы, уникальные ключи, полнота, согласованность двух endpoint и целостность SQLite. Сначала строится временная база, затем выполняется атомарная замена. Предыдущая версия остаётся в `nobel_database.sqlite.bak` локально; в GitHub история базы сохраняется коммитами. При ошибке старая база остаётся рабочей; процесс возвращает ненулевой код.

В GitHub Actions обновление запланировано **по понедельникам, 04:17 UTC / 07:17 по Москве**. Это конфигурация внутри проекта, а не уже включённая задача в вашем аккаунте. Запуски Actions могут задерживаться; в неактивных публичных репозиториях расписание может отключаться. Следите за результатом первого запуска и уведомлениями GitHub о сбоях.

## Дополнительные сведения Wikidata

Официальный API — основной источник. В пакете реализовано дополнительное обогащение, но в готовой базе **оно ещё не выполнялось**: адрес вашего проекта для корректного User-Agent неизвестен.

```bash
# macOS / Linux — подставьте свой настоящий адрес:
export NOBEL_USER_AGENT='NobelAtlas/2.0 (https://github.com/YOUR_ACCOUNT/YOUR_REPO)'
python updater.py --wikidata
```

PowerShell:

```powershell
$env:NOBEL_USER_AGENT='NobelAtlas/2.0 (https://github.com/YOUR_ACCOUNT/YOUR_REPO)'
python updater.py --wikidata
```

Либо запустите workflow вручную с флажком `wikidata`: он сам подставляет URL текущего репозитория. Кэш 90 дней; запросы пакетами до 50 QID, последовательно, с `maxlag=5`. Загружаются русские/английские имена и описания, все утверждения, квалификаторы, ссылки на источники и sitelinks. Один дополнительный проход получает связанные места, учебные заведения, работодателей, гражданства, профессии и области исследований. Работодатели за всю жизнь не подставляются в карту вместо аффилиации на дату премии.

Координаты Wikidata используются только для точного QID города из официального `cityNow.sameAs` и только когда официальные координаты отсутствуют. Источник такого дополнения хранится отдельно. Ошибка обогащения отменяет весь запуск, сохраняя прежнюю базу; обычный запуск без `--wikidata` всегда доступен.

Автоматическое еженедельное обновление по умолчанию обращается только к Nobel API. Чтобы включить Wikidata регулярно, используйте `python updater.py --wikidata` в этом шаге workflow: 90-дневный кэш ограничит повторные обращения.

## Сервер и будущий n8n

```bash
pip install -r requirements-api.txt
uvicorn api:app --host 127.0.0.1 --port 8000
```

Документация: `http://127.0.0.1:8000/docs`.

- `GET /health`, `/meta` — статус и версия данных.
- `GET /laureates?q=Curie&limit=20` — поиск с пагинацией.
- `GET /laureates/6` — полная официальная запись по ID.
- `GET /awards?category=Physics&year_from=2000` — награждения.
- `GET /stats?birth_country=Germany` — агрегаты.
- `GET /export.csv` — выборка CSV.

При заданном `NOBEL_API_KEY` запросы должны содержать заголовок `X-API-Key`. Сервер только читает данные; публичной команды парсинга нет. **Streamlit Community Cloud не служит хостингом для этого второго процесса**: FastAPI запускается отдельно, например на вашей машине или другом сервере. Бот/n8n ещё не настроен и не опубликован. Подробнее: [docs/N8N.md](docs/N8N.md).
