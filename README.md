# ✦ Nobel Atlas

**Люди, открытия и география знаний.** Исследовательское приложение на Python и Streamlit с полной локальной базой Nobel Prize API.

**Автор: Денис Брель.** Университетский проект по Python.

## Возможности

- Карта при открытии сайта: рождение людей и основание организаций, работа / расположение, места смерти. Цвет обозначает категорию, форма — тип места. Все карты масштабируются колесом мыши.
- Поиск по имени, формулировке заслуг и учреждениям; общие фильтры по годам, категории, типу лауреата, стране, городу, возрасту и другим признакам.
- Карточки людей и организаций со всеми премиями, датами, формулировками заслуг, аффилиациями, ссылками и исходным JSON.
- 13 основных видов визуализации и дополнительный график повторных награждений организаций. Дополнительные разделы вычисляются при открытии.
- Карта связей: рождение → работа для людей, основание → официальное расположение для организаций. Лимит — от 0 до числа уникальных лауреатов в выборке. Отсутствующие места не выдумываются.
- Лаборатория со сводными таблицами, тепловыми картами, CSV и полными записями JSON. Готовый экспорт сбрасывается при изменении выборки.
- Раздел о данных: объём снимка, наличие и точность дат, полнота координат, реестр премий и методология.
- Отдельный обновлятор с GitHub Actions и необязательный HTTP API для будущего бота/n8n.

На первом экране находятся вкладки и карта. Сведения об источнике, авторе, GitHub, Fork и печать — внизу страницы. Печать включает открытое содержимое текущей вкладки; заранее раскройте нужные блоки.

## Локальный запуск

Рекомендуется **Python 3.12**. Откройте терминал в корне репозитория:

```bash
python -m venv .venv
```

Активируйте окружение одной командой для своей системы:

```bash
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS / Linux
source .venv/bin/activate
```

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Готовая SQLite уже включена. Парсинг перед первым запуском не требуется. Карты используют локальную подложку и не требуют Mapbox-ключа.

## Streamlit Community Cloud

1. Репозиторий: `Denbrel/nobel_atlas`, ветка `main`.
2. **Main file path: `app.py`**; Python **3.12** в Advanced settings при создании приложения.
3. Сохраните структуру проекта целиком, включая `nobel`, `static`, `.streamlit` и `nobel_database.sqlite`. Обновляйте взаимосвязанные Python-файлы одним коммитом.
4. После замены модулей выполните Reboot app, чтобы процесс использовал новые классы и функции.

Сайт только читает базу. Обновлённая SQLite попадает на него вместе с новым коммитом репозитория. Файл `.streamlit/config.toml` включает локальную подложку карт и минимальную служебную панель.

## Данные и обновление

```bash
python updater.py
```

Импортируются все страницы `laureates` и `nobelPrizes`: первичные JSON сохраняются полностью, вложенные записи нормализуются для анализа. Новая база заменяет прежнюю только после проверок полноты, согласованности endpoint и целостности SQLite. При ошибке остаётся предыдущая версия. Посещения сайта не вызывают запросов к API.

В GitHub Actions подготовлен workflow **Update Nobel data**: понедельник, 04:17 UTC / 07:17 по Москве, а также ручной запуск. Для записи базы нужны разрешения Actions на изменение репозитория; правила защищённой ветки должны разрешать выбранный процесс обновления.

**Wikidata необязательна.** Для ручного обогащения откройте Actions → Update Nobel data → Run workflow → включите `wikidata`. Адрес проекта для User-Agent workflow подставляет сам. При локальном запуске команды и объяснение `NOBEL_USER_AGENT` приведены в [инструкции обслуживания](docs/OPERATIONS.md#wikidata-для-автора-проекта). Посетителям сайта ничего настраивать не нужно.

Дата снимка и число записей отображаются на сайте из самой базы. Координаты из справочника совпадающих городов считаются производными, подписываются отдельно и не изменяют исходные JSON.

## HTTP API

```bash
python -m pip install -r requirements-api.txt
uvicorn api:app --host 127.0.0.1 --port 8000
```

Документация: `http://127.0.0.1:8000/docs`. Маршруты: `/health`, `/meta`, `/laureates`, `/laureates/{id}`, `/awards`, `/stats`, `/export.csv`.

FastAPI запускается отдельно от Streamlit Community Cloud. При заданном `NOBEL_API_KEY` требуется заголовок `X-API-Key`. Подробнее: [подключение n8n](docs/N8N.md).

```bash

python scripts/check_deployment.py
python -m pytest -q
```
