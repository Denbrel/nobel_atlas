# Источники и методология

## Официальные данные

- [Nobel Prize API — документация](https://www.nobelprize.org/about/developer-zone-2/).
- [Laureates 2.1](https://api.nobelprize.org/2.1/laureates): люди, организации и все их награждения.
- [Nobel Prizes 2.1](https://api.nobelprize.org/2.1/nobelPrizes): премии по году и категории, включая записи без получателей.
- [Условия использования](https://www.nobelprize.org/about/terms-of-use-for-api-nobelprize-org-and-data-nobelprize-org/).

В `source_pages` сохранены полные страницы с `meta` и `links`. В `raw_json` — исходные записи. Неизвестные приложению поля не удаляются. Разделы карточки и CSV показывают аналитическое представление; полный JSON содержит все языки, ссылки, примечания и вложенные данные.

## Единицы подсчёта

Лауреат — человек или организация с уникальным Nobel ID. Награждение — пара «лауреат × премия». Премия — «год × категория»: число получателей не умножает её денежную сумму. Один человек может относиться к нескольким учреждениям; числа по учреждениям нельзя складывать как число уникальных людей.

На точечной карте один лауреат показывается один раз. Если в выборке есть несколько его категорий, цвет соответствует последней выбранной премии; при одинаковом годе используется устойчивый порядок ключа. Все категории и годы перечислены при наведении.

## Даты

Наличие строки даты не гарантирует точного дня: API допускает `YYYY-00-00` и неизвестный день. Сайт отдельно показывает наличие записи и точную календарную дату. Возраст вычисляется на `dateAwarded`, если обе даты полны; иначе используется разность года премии и известного года рождения. Это не всегда дата церемонии. Срок существования организации показывается отдельно и оценивается по годам.

## Организации и координаты

Для людей исходная точка — рождение, для организаций — основание. Поля `birth_*` и `founded_*` не смешиваются; общее аналитическое представление называется `origin_*`.

Координаты по приоритету:

1. Координаты города в официальной записи (или ранее сохранённое обогащение точного QID города из Wikidata).
2. Локальный справочник по точному совпадению современных названий **города и страны** среди записей Nobel. Используется только одна непротиворечивая пара координат. Источник: «Nobel API: совпадение города и страны».
3. Если совпадения нет или оно неоднозначно, координаты остаются неизвестными.

Справочник строится из полного снимка до применения фильтров и не делает сетевых запросов. Это вывод по совпадающим топонимам, а не координаты, непосредственно указанные в записи организации. Одинаково названные города внутри страны теоретически возможны даже при одном кандидате; происхождение дополнения явно подписано. Центры стран не используются.

Вторая точка людей — аффилиация при награждении, организаций — официальное `residences` из записи о премии. Эти сведения не заменяются современными штаб-квартирами. При отсутствии второй точки на карте связей остаётся контурный ромб основания без линии.

Карта связей не восстанавливает путь миграции и не доказывает место открытия. Одна связь на лауреата выбирается по последнему выбранному награждению с координатами и первой подходящей записи в порядке API. Лимит влияет только на показанные связи, не на статистику. Значение 0 скрывает связи; одиночные основания остаются. Расстояния меньше 1 км сохраняют маркеры без дуги.

## Дополнительные источники

[Wikidata API](https://www.wikidata.org/w/api.php) используется необязательно: имена, описания, утверждения, квалификаторы и источники. Образование и работодатели за всю жизнь не подменяют место работы при премии. Кэш хранит время загрузки, по умолчанию обновляется через 90 дней. Правила запросов: [API etiquette](https://www.mediawiki.org/wiki/API:Etiquette), [User-Agent](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy).

Краткое описание Wikidata не является полной биографией; ссылки на первичные страницы доступны в карточках. Условия данных Wikidata — [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing).

Подложка `static/world_110m.json` — Natural Earth в формате TopoJSON, распространяемая через [Plotly geo assets](https://cdn.plot.ly/un/world_110m.json). Исторические границы государств отдельно не реконструируются; сведения источника об исторических названиях сохраняются.
