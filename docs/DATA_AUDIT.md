# Аудит данных и методология

Проверены все пять предоставленных файлов: `app.py`, `updater.py`, `requirements.txt`, `update_data.yml`, `nobel_database.sqlite`. Исходные файлы оставлены без изменения; новый пакет — отдельная версия.

## Что было в исходном проекте

База целостна, содержит 1 028 лауреатов и 1 036 награждений за 1901–2026 годы. Координаты рождения были у 974 лауреатов; координаты первого места работы — у 756 награждений.

Исходный загрузчик сохранял только небольшой набор полей, год рождения вместо даты, одну аффилиацию, без сведений о смерти и доли премии. Его `fetch` прерывал цикл при любой ошибке и возвращал уже загруженную часть. Затем `DatabaseManager` удалял старые таблицы. Поэтому частичный ответ мог стать новой «полной» базой. В исходных зависимостях не было `requests`, хотя обновлятор его использовал; workflow устанавливал его отдельно. Старое приложение исключало строки без координат из всех видов анализа и считало возраст простой разностью лет.

## Правила анализа

- **Человек/организация:** организации не смешиваются с возрастом людей, но учитываются в награждениях. Их данные основания доступны в карточке.
- **Возраст:** при полных датах — завершённые годы на `dateAwarded` с проверкой дня рождения; иначе — год премии минус год рождения, помечено `year_estimate`. `dateAwarded` не интерпретируется как дата фактического вручения.
- **Место премии:** используется аффилиация на момент присуждения. Не используется город церемонии. Дата и место научного открытия в общем случае отсутствуют в API; они не выдумываются.
- **Миграция:** это связь двух наблюдаемых мест. Одна отображаемая связь на человека — последнее выбранное награждение с полной парой координат, затем первая аффилиация с координатами в порядке API. Все остальные аффилиации сохранены, доступны в карточке, таблицах и фильтрах. Можно использовать `AnalyticsService.routes(..., one_per_person=False)` для исследования всех связей.
- **Прозрачность карты:** по умолчанию 60 воспроизводимо выбранных связей длиннее 1 км; максимум 200. Подпись показывает полный знаменатель. Sankey считает весь набор связей, затем показывает крупнейшие потоки с указанием покрытия. Связи внутри одной страны остаются.
- **Координаты:** городские точки из `cityNow`, не центры стран. Нулевые координаты допустимы. Строки с отсутствующими координатами не исчезают из негеографической статистики. Ссылки через линию смены дат разделены, чтобы не пересекать всю карту.
- **Страны:** основные фильтры используют `countryNow`, исторические названия хранятся отдельно. Страна рождения не равна гражданству. Исторические границы на карте не реконструируются.
- **Учреждения:** учитывается уникальный человек в каждой организации, а не число дублирующихся премий. Суммировать такие рейтинги нельзя. Варианты исторических названий автоматически не объединяются.
- **Суммы:** сумма премии дедуплицируется по «год × категория». Доля `portion` хранится отдельно. `prizeAmountAdjusted` отображается без выдуманного базового года индексации.
- **Жизненный статус:** отсутствие `death` не является доказательством того, что человек жив.

## Что стоит развивать дальше

Наиболее полезное следующее расширение — проверенный справочник учреждений с объединением исторических названий, затем образование и места работы с временными квалификаторами из Wikidata. Для «места открытия» нужна отдельная доказательная модель: публикация/открытие → дата → учреждение → источник. Автоматически приравнивать её к месту награждения нельзя.
