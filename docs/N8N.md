# Подключение к n8n

Подготовлен API для чтения, поиск, пагинация и стабильные ID. Сам бот не создан: его канал, аккаунты, способ размещения n8n и сценарии ещё не определены.

## Самый короткий рабочий сценарий

1. Запустите `api.py` командой из README и откройте `/docs`.
2. В n8n создайте Manual Trigger → HTTP Request.
3. В HTTP Request выберите Import cURL и вставьте:

```bash
curl 'http://127.0.0.1:8000/stats?category=Physics&year_from=2000'
```

4. Выполните workflow. В ответе будут `laureates`, `award_credits`, `prizes`, разбивка по годам и категориям.
5. Для поиска вместо `/stats` используйте `/laureates?q=Curie&limit=50&offset=0`; для карточки — `/laureates/{laureate_id}`.

`127.0.0.1` работает только если n8n и FastAPI находятся в одной сетевой среде. Из Docker нужен адрес сервиса/хоста в вашей сети; из n8n Cloud — доступный HTTPS-адрес отдельно размещённого API. URL приложения `*.streamlit.app` не является URL FastAPI.

Если на сервере задан `NOBEL_API_KEY`, добавьте в n8n Generic Credential → Header Auth: имя `X-API-Key`, значение — ваш секрет. Не сохраняйте реальный ключ в экспортируемом workflow или репозитории.

## Пагинация и фильтры

Максимум 200 результатов на страницу. Увеличивайте `offset` на `limit`, пока `offset + len(items) >= total`. Массивы фильтров передаются повторяющимися параметрами, например `category=Physics&category=Chemistry`. Годы и категории относятся к награждениям: `/laureates` возвращает уникальных людей/организации, у которых есть подходящее награждение.

## Будущий бот

Логичная цепочка: входящее сообщение → разбор имени/фильтров → GET `/laureates` → при нескольких совпадениях выбор пользователя → GET `/laureates/{id}` → краткий ответ со ссылкой на официальный источник. Биографию не следует додумывать из краткой формулировки заслуг; отсутствие данных надо показывать явно.

Для уведомлений о новых данных сравнивайте `/meta.content_hash` с сохранённым значением. Отправку сообщений, расписание и канал надо настроить отдельно. Такой workflow не будет заново обращаться к Nobel API при каждом запросе бота.

Документация: [n8n HTTP Request](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest/).
