## Не выполнено в этой среде

Полноценная визуальная проверка страниц в браузере не завершилась: Chromium завершался с сигналом SIGTRAP до открытия страницы, в том числе на пустой странице. Поэтому не заявляется проверка скриншотов, мобильной вёрстки и фактического рисования карты в браузере. Код графиков, сериализация фигур, компоненты Streamlit и выдача подложки проверены отдельно. После размещения нужно проверить карту, легенды, карточку и ширину колонок в своём браузере.

Wikidata не загружалась в поставляемую базу: нужен User-Agent с реальным адресом проекта/контактом. Поддержка подготовлена и проверена на контролируемых ответах. Боевой workflow GitHub Actions, размещение на Streamlit и соединение с n8n здесь не запускались: репозиторий, аккаунты и URL пользователя не предоставлены.

## Команды воспроизведения

```bash
pip install -r requirements-dev.txt
python -m pytest -q
python updater.py
streamlit run app.py
```

Отдельный API:

```bash
uvicorn api:app --host 127.0.0.1 --port 8000
```

Перед публикацией достаточно проверить домашнюю страницу, поиск `Curie`, фильтр `Peace`, карту работы и миграционный блок. Инструкции переноса — в корневом README.
