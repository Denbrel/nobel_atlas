## Что именно проверено

- Исходная версия из GitHub отдельно установлена в чистый Python 3.12.14 с исходным pandas 2.2.3. Установка и старт через AppTest успешны, 13 графиков. Это не позволяет приписать зависание Cloud доказанной ошибке исходного `app.py`.
- Контрольная попытка установить pandas 2.2.3 из готового пакета на Python 3.14 воспроизводимо отклонена: подходящих wheels нет. Исправленный requirements устанавливается.
- Streamlit AppTest: шесть графиков при старте, три режима карты, организации, пустой поиск, сброс фильтров, Curie, возраст по категориям, годовая динамика, переключение вкладок, карточка, раскрытие JSON, выгрузка, сводная таблица, миграционные графики, дополнительные диаграммы и реестр премий.
- Закрытые вкладки не формируют таблицы и JSON. Дополнительные графики возникают после раскрытия соответствующих блоков; суммарно доступны прежние 13 видов визуализации.
- Пакетный экспорт JSON возвращает исходные записи, убирает дубликаты ID и корректно обрабатывает пустой список / неизвестные ID.
- Возраст, нулевые координаты, несколько аффилиаций, отсутствующие сведения, подсчёты и фильтры проверяются прежними тестами.
- Сохранность прежней SQLite при неполной загрузке, ошибках и сбое нормализации, повторный импорт, миграция старой схемы и кэш Wikidata проверены на тестовых ответах.
- FastAPI TestClient: статус, поиск, фильтры, пагинация, полная карточка, 404/422, CSV и API-ключ.
- `scripts/smoke_http.py` запускает настоящий локальный Streamlit, проверяет здоровье, HTML и **все установленные JS/CSS-файлы**, включая `static/js/Button.BNvfR8OZ.js`. HTTP-тела сверяются через SHA-256 с установленным пакетом. Затем проверяется `/app/static/world_110m.json`.
- Ячейки Colab-ноутбука проходят синтаксический разбор. Проверена остановка только принадлежащих помощнику процессов. Официальный `cloudflared` скачан, SHA-256 совпал, `--version` вернул 2026.10.5.
- Исправления не меняют файл базы из репозитория.

## Границы проверки

Проверка HTTP-выдачи файлов не равнозначна выполнению JavaScript в браузере. Chromium в доступной среде завершался с SIGTRAP даже на пустой странице; визуальная проверка, WebSocket-сессия браузера и мобильная вёрстка не подтверждены. AppTest проверяет выполнение Python-кода и формирование элементов, а не отрисовку в браузере.

Не выполнялись: вход в аккаунт Streamlit пользователя, новое облачное развёртывание, запуск в настоящей среде Google Colab и создание публичного Cloudflare-туннеля. Ноутбук и локальные компоненты проверены отдельно. Гарантия доступности внешних сервисов не заявляется.

Точная причина исходного ожидания Cloud остаётся неизвестной: предоставленный журнал заканчивается на подготовке машины / `Processing dependencies`. При повторном зависании нужны полный журнал, выбранная версия Python и URL сайта.
