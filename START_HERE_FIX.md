# Исправление запуска Nobel Atlas

Пакет от 29 октября 2026 для `Denbrel/nobel_atlas`, ветка `main`.
Основа: коммит `b60554d90a55d20c362875b1e4cb41885b968004`.

## Установка исправлений

1. Сохраните текущую версию репозитория коммитом.
2. Распакуйте **содержимое** `nobel_atlas_deploy_fix.zip` в корень репозитория, рядом с существующим `app.py`, с заменой одноимённых файлов. Сохраните вложенность папок, включая `.github`. Не создавайте ещё одну вложенную папку проекта.
3. Архив содержит только исправленные и новые файлы. **Не удаляйте остальные файлы.** В частности, `nobel_database.sqlite`, `updater.py`, `api.py`, `static` и остальные модули уже находятся в репозитории и нужны приложению. База этим пакетом не заменяется.
4. Загрузите изменения в GitHub и сделайте commit. В Actions проверьте новый запуск **Tests**: он проверяет Python 3.12, 3.13 и 3.14.
5. В Streamlit используйте `Denbrel/nobel_atlas`, ветку `main`, **Main file path: `app.py`**. Рекомендуемая версия — **Python 3.12** в **Advanced settings** при создании приложения.

Изменение `requirements.txt` вызывает переустановку зависимостей. Если существующий экземпляр остаётся на `Provisioning machine` / `Processing dependencies`, создайте новое развёртывание. Если интерфейс требует удалить старое, сначала сохраните его адрес, настройки и secrets, затем пересоздайте. **Reboot не меняет версию Python**; версия выбирается при создании приложения. Не нужно удалять репозиторий или базу.

После запуска проверьте карту, поиск `Curie`, вкладки, фильтр `Peace`, раскрываемую карту миграции и выгрузку JSON в «Лаборатории».

## Что было обнаружено

Две ошибки относятся к разным этапам:

- **Community Cloud:** предоставленные логи обрываются на установке зависимостей и подготовке машины; в них нет Python traceback из `app.py`. Из этих строк нельзя достоверно установить причину 40-минутного ожидания. Исходные зависимости и исходное приложение успешно проверены в отдельном чистом Python 3.12. Поэтому утверждать, что старый код сам по себе всегда блокировал запуск, неверно.
- **Совместимость Python:** у `pandas==2.2.3` нет готовых пакетов для Python 3.14. Попытка установить его с `--only-binary=:all:` в 3.14 воспроизводимо завершается ошибкой. Обновлено до `pandas==2.3.3`, поддерживающего 3.14. Установка теперь использует только готовые пакеты: вместо долгой попытки компиляции несовместимость будет видна сразу. Выбранная в вашем Cloud версия Python неизвестна, поэтому это устранённый риск, а не доказанная причина вашего зависания.
- **Colab/localtunnel:** `Failed to fetch dynamically imported module` означает, что браузер не смог загрузить модуль интерфейса Streamlit. Файл `Button.BNvfR8OZ.js` присутствует в установленном Streamlit. При проверке указанный пользователем URL также вернул JavaScript с HTTP 200 — постоянное отсутствие файла не воспроизвелось. Временный сбой туннеля, старый кэш или прежний сервер после повторных запусков возможны, но точный вариант без сетевого журнала браузера неизвестен.
- **Нагрузка при открытии:** раньше скрытые вкладки и свёрнутые блоки тоже выполнялись; формировались 13 графиков, таблицы и полный JSON со множеством отдельных чтений SQLite. Теперь главная страница строит шесть основных графиков. Остальные появляются при открытии соответствующих разделов; JSON готовится по кнопке и читается пакетами через одно соединение с базой.

Все 13 визуализаций, фильтры, карточки и исходные записи API сохранены. Streamlit 1.66.1 закреплён намеренно: приложение использует его поддержку вкладок и раскрываемых блоков с выполнением по запросу.

## Colab: новый способ запуска

1. Сначала загрузите пакет исправлений в GitHub.
2. В Google Colab откройте `notebooks/Nobel_Atlas_Colab.ipynb` из обновлённого репозитория или загрузите этот файл из архива. Начните с новой среды выполнения.
3. По очереди выполните ячейки установки, проверки файлов и открытия приложения. Откройте выданную **новую** ссылку `trycloudflare.com` в отдельной вкладке. Старые команды `streamlit run ... & npx localtunnel ...` больше не нужны.
4. Диагностическую ячейку запускайте при необходимости. Ячейку **«Остановить предпросмотр»** выполняйте только после завершения работы, иначе ссылка сразу перестанет работать.

Ноутбук создаёт отдельную Python-среду, проверяет готовность сервера, использует свободный порт и управляет только своими процессами. `cloudflared` загружается из официального релиза с проверкой SHA-256. Пароль в виде IP не нужен. Защита CORS/XSRF остаётся включённой.

Ссылка общедоступна и временная: работает только при активной среде Colab и процессе туннеля. Quick Tunnels предназначены для тестирования и не гарантируют доступность. Постоянное размещение проекта остаётся на Streamlit Community Cloud.

Если ошибка модуля появилась уже на новом адресе, откройте его в приватном окне либо выполните полную перезагрузку страницы. Если не помогло, в инструментах браузера → Network найдите упавший запрос `.js` и сохраните его статус, `Content-Type` и начало ответа. Это покажет, пришёл ли JavaScript, HTML-страница ошибки или сетевой отказ.

## Проверки

В чистых Linux-окружениях Python **3.12.14** и **3.14.8**: установка зависимостей, проверка совместимости пакетов, **35 тестов на каждой версии**, запуск настоящего HTTP-сервера и успешная выдача всех **307 JS/CSS-файлов** и локальной подложки карты. Сравниваются MIME-типы и SHA-256 полученных файлов. Подробности — [docs/VALIDATION.md](docs/VALIDATION.md).

```bash
python -m pip install -r requirements-dev.txt
python -m pip check
python scripts/check_deployment.py
python -m pytest -q
python scripts/smoke_http.py
python -m streamlit run app.py
```

Это не подтверждение исправности вашего облачного экземпляра: доступ к управлению Cloud и его полным журналам отсутствовал. Визуальная проверка в браузере и живой запуск в Colab в этой среде не выполнены. Если Cloud снова зависнет, нужны **полные логи установки после `Processing dependencies`**, выбранная версия Python и адрес `*.streamlit.app`. Если журнал не доходит до установки пакетов, проблема требует проверки самого развёртывания на стороне Cloud.
